# Shared nxnative runtime

This directory retains the shared runtime and source tools used by [Resident Evil Native](../README.md). Other game profiles remain as shared tooling inputs and regression fixtures.

Original project: [seedds/nxnative](https://github.com/seedds/nxnative). Android fork: [shirai91/nx2android](https://github.com/shirai91/nx2android).

See [LICENSE](LICENSE), [third-party notices](dm/third_party/README.md), [development internals](docs/development.md), and [attribution](../ATTRIBUTION.md). The prebuilt iOS translator and game screenshots are excluded from this source export; Android builds its translator from source.
